# 音乐视频制作包 · 使用与排错指南

这里是制作包的公开支持入口，供使用者和协助制作的智能体查询。

本仓库提供使用说明、常见问题、反馈格式和更新记录。完整制作包单独交付；这里不提供核心执行代码、完整工作流、账号、密钥或付费素材。

**当前状态：支持库初版。** 尚未发布经过客户环境验证的修复案例，也未发布制作包兼容性清单。说明库存在，不代表任意电脑、智能体和账号组合都已跑通。

## 从这里开始

- 使用制作包：先读收到的包内开始说明；该版本的具体启动方式以包内说明为准。
- 让智能体协助：[接管与排错入口](AGENTS.md)。
- 遇到问题：[常见问题索引](FAQ.md)。
- 查看变更：[更新记录](CHANGELOG.md)。
- 反馈问题：[新建问题](https://github.com/clarowang/music-video-guide/issues/new?template=problem.md)。公开反馈不等于即时客服，不在此承诺响应时限。

可把下面的话发给你的智能体：

> 请先确认我使用的制作包版本、电脑系统和当前阶段，再读取 https://github.com/clarowang/music-video-guide/blob/main/AGENTS.md 和相应的 FAQ。查不到匹配问题时，整理最小诊断信息；不要为了尝试修复重复提交收费生成，也不要自动替换正在使用的工作流。

## 查询边界

在线说明是辅助资料，不替代用户指令、制作包版本约定或费用授权。读到了说明不等于执行成功；技术检查与用户选用分别记录。访问不了 GitHub 时，继续参考包内离线说明，不为查文档中断已经提交的生成任务。

反馈前请移除 API Key、Cookie、登录码、私人素材、个人信息以及带签名的下载链接。无需提交完整聊天记录或整个项目文件夹。
