# 音乐视频制作包 · 购买前评估与使用支持

这里是制作包的公开评估与支持入口。购买前，可以让自己的智能体判断是否适合；购买后，可查询说明和排错。

本仓库提供使用说明、常见问题、反馈格式和更新记录。完整制作包单独交付；这里不提供核心执行代码、完整工作流、账号、密钥或付费素材。

**当前制作包：0.1.0-alpha.1，内部试用阶段，先验证 Mac + Codex。** 卖方已做离线程序与模拟流程检查，尚无陌生客户完整交付验收；其他客户端和 Windows 未认证。完整验证范围见产品说明，不能把支持库存在当作已经全面可用。

## 先让你的智能体判断，适不适合你

**[阅读产品能力、门槛、服务和验证状态 →](PRODUCT.md)**

将下面整段发给自己的智能体即可：

> 请阅读 https://github.com/clarowang/music-video-guide/blob/main/PRODUCT.md 。结合我的制作目标、电脑、当前智能体和账号条件，独立判断这套音乐视频制作包是否适合我。区分卖方声明、已提供的验证证据和你尚未实测的部分；明确缺哪些条件、有哪些额外费用，以及购买前还要核实什么。可以建议我暂缓或不买，不要为了评估安装、上传或付费。缺少关键信息再问我，不要要求我先购买制作包。

它能帮你做适配判断，不能仅凭一篇说明替你完成验货。本公开库不含主体实现，完整包单独交付。

## 从这里开始

- 使用制作包：先读收到的包内开始说明；该版本的具体启动方式以包内说明为准。
- 让智能体协助：[接管与排错入口](AGENTS.md)。
- 核对自己使用的客户端：[适配现状与能力检查](CLIENTS.md)。文档入口与本机开发检查不等于客户整链兼容认证。
- 遇到问题：[常见问题索引](FAQ.md)。
- 查看变更：[更新记录](CHANGELOG.md)。
- 反馈问题：[新建问题](https://github.com/clarowang/music-video-guide/issues/new?template=problem.md)。公开反馈不等于即时客服，不在此承诺响应时限。

可把下面的话发给你的智能体：

> 请先确认我使用的制作包版本、电脑系统和当前阶段，再读取 https://github.com/clarowang/music-video-guide/blob/main/AGENTS.md 和相应的 FAQ。查不到匹配问题时，整理最小诊断信息；不要为了尝试修复重复提交收费生成，也不要自动替换正在使用的工作流。

## 查询边界

在线说明是辅助资料，不替代用户指令、制作包版本约定或费用授权。读到了说明不等于执行成功；技术检查与用户选用分别记录。访问不了 GitHub 时，继续参考包内离线说明，不为查文档中断已经提交的生成任务。

反馈前请移除 API Key、Cookie、登录码、私人素材、个人信息以及带签名的下载链接。无需提交完整聊天记录或整个项目文件夹。
